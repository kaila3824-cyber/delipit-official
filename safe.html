安全を、毎日の流れに。

日常点検、点呼、業務開始・終了、走行記録。軽貨物ドライバーが毎日の安全管理と業務記録を続けやすくするためのDELIPITシリーズ新プロダクト。

WHAT IS SAFE?

記録のために、仕事を止めない。

DELIPIT SAFEは、配送現場で必要になる安全確認や業務記録を、日々の流れに沿って扱えるよう設計しています。

01 DAILY CHECK日常点検
02 ROLL CALL業務前点呼
03 ON DUTY業務開始・業務中
04 FINALIZE業務終了・記録確定
SAFE NAVIGATORS

FUUが状態を伝え、RONAが次を案内する。

SAFEでは、情報を増やすだけではなく「今どういう状態か」「次に何をすればいいか」を直感的に分けて伝えます。

FUU

STATUS COMMUNICATION
現在の安全・記録状態を伝えるSAFEナビゲーター。NORMAL / CHECK / ALERT / COMPLETEなど、状況に応じて状態を変えます。

RONA

GUIDED COMPLETION
ユーザーが次に行う操作や確認を案内するナビゲーター。FUUとは役割を分け、日々の流れをサポートします。

FUU STATES

状態が変われば、FUUも変わる。

FUUは飾りではなく、SAFEの状態コミュニケーションを担うキャラクターです。公開テスト中のため、表示条件や表現は調整される場合があります。

NORMAL

通常状態。

CHECK

確認が必要な状態。

ALERT

対応が必要な問題を通知。

EMPTY

確認対象がまだない状態。

COMPLETE

必要な流れを完了。

WELCOME BACK

FINALIZE後の帰還を迎える状態。

SECURITY & DATA

業務記録を、端末内で守る。

SECURITY

暗号化とUnlock

端末内の記録を保護するためのセキュリティ設計を採用。公開テストを通して安全性と使いやすさを検証しています。

BACKUP

Backup / Restore

端末内だけに依存しないよう、記録のBackup / Restoreを用意しています。

PRIVACY

現場を追跡しない

位置情報は必要な入力補助のために扱い、常時追跡を前提としない設計です。
