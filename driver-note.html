DRIVER NOTE

配送の現場から、残しておきたいこと。

現役の業務委託配送ドライバーとして働くSORAが、毎日の配送、数字の管理、仕事の考え方を実体験から書いています。

DRIVER NOTE #01

売上を確認するために記録していたら、自分がやってきた仕事が見えてきた。

配送の数字を記録し始めた一番の理由は、売上の確認と実際の入金チェックでした。最初はメモで残していましたが、さすがに管理には向かない。そこで自分用のGoogleスプレッドシートを作り...

DRIVER NOTE #02

売上だけ見ていた頃より、仕事の調子が分かるようになった。

以前は、その月にいくら売り上げたかが分かれば十分だと思っていました。でも記録を続けると、同じ売上でも中身が違うことに気づきます。...

DRIVER NOTE #03

計算と入金額が合わない。でも、間違いとは限らなかった。

配送実績から自分で計算した金額と、実際に振り込まれた金額が合わないことがあります。僕の場合は、実際の金額の方が高いことが多くありました。...

DRIVER NOTE #04

カレンダーを数字で埋めていくと、一ヶ月働いた実感が残る。

月の配完数や売上だけを見ても、その一ヶ月をどう働いたかまでは分かりません。そこで日付ごとの数字をカレンダーで見られるようにしました。...

DRIVER NOTE #05

僕にとって配送は、身体を使った『攻略ゲーム』だった。

僕は小さい頃からゲームが好きで、配送の仕事も一種のゲーム感覚でやっています。この家はこの時間なら在宅していそう、朝の時間指定はこの数だから指定なしを先に回れる、間に合わなくなりそう...

DRIVER NOTE #06

最初は、仲のいい人にも使ってもらえたら。それくらいだった。

DELIPITを作る前は、自分で作ったGoogleスプレッドシートで配送の数字を管理していました。自分用としては割と満足していて、仲のいい人にも使ってもらえたらと思っていました。...

DRIVER NOTE #07

配送の一日は、荷物を積む前から始まっている。

営業所に着くと自分の担当のラックが用意されています。僕の稼働環境では、朝は基本的に午前指定と指定なしの荷物が中心です。通常時で130〜150個前後、繁忙期には200個を超えることも...

DRIVER NOTE #08

荷物が多い日より、『不在が多そうな日』の方が難しい。

荷物が多くても在宅が多ければ、一件届けるたびに荷台は空いていきます。僕の場合、むしろ『今日は不在が多そうだな』と感じる日の方が組み立てが難しくなります。...
