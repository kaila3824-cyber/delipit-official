DELIPIT GAME SYSTEM / V1.0.0

仕事の記録を、キャリアへ。

GAME MODEは、配送を競争に変えるための機能ではありません。いつもの配送記録を、LEVEL・CAREER CLASS・Achievement・Personal Bestなど、自分自身の積み重ねとして残します。

OPTIONAL

GAMEを使わなくても、DELIPITは使えます。

GAME MODEは任意です。OFFでも配送実績、売上、経費、月間・年間集計などのCORE機能はそのまま利用できます。

比べるのは、他人ではなく過去の自分。

他者ランキング、速度競争、連続勤務を促すボーナスは設けません。安全を優先し、自分の記録・成長・達成感を中心にしています。

FIRST START

初めてGAMEをONにすると、あなたの記録を読み込みます。

V1.0.0ではGAME画面を開いたあと、GAME SYSTEM FIRST STARTが始まります。過去の配送履歴がある場合は、現在の記録からDRIVER STATUSを復元します。

履歴がある場合

TOTAL DELIVERY、EXP、LEVEL、CAREER CLASSを既存の配送記録から表示し、DRIVER STATUSを復元します。

初めて記録する場合

NEW DRIVERとしてDRIVER STATUSを作成し、これからの配送記録を積み上げます。

初回演出はSKIPできます。SKIPしても配送記録やGAMEデータは変更されません。一度完了した初回演出は、通常のOFF→ONで繰り返し発生しません。
FIRST STARTはアプリ内で実際の画面を案内するため、ここでは通常のGAME画面を中心に紹介します。
DRIVER STATUS

届けた数が、そのまま経験になる。

DRIVER LEVEL

1 DELIVERY = 1 EXP。 日々の配完が経験値として積み上がり、DRIVER LEVELとして残ります。

CAREER CLASS

単日の結果ではなく、積み重ねてきた配送実績をキャリアとして表示します。

RECORDS

いつもの仕事が、達成の記録になる。

Achievement / Personal Best

日々の配送や累積キャリアの節目をAchievementとして記録。DAILY BEST、MONTHLY BESTなど、自分自身の更新も残します。

Monthly Rank

直近3か月の自分の実績を基準に、その月のDAILY AVGを振り返ります。比較に必要な履歴が揃うまではCALIBRATINGと表示されます。

Monthly Result

稼働日数、配完数、DAILY AVG、記録など、その月の積み重ねをまとめて確認します。

SHARE CARD

その月の成果を、1枚に。

MONTHLY RESULTをSHARE CARDとして画像化できます。保存して自分の記録として残すことも、仲間やSNSへ共有することもできます。

共有する内容は自分で選ぶ。

売上表示など、カードに載せる情報を選択できます。共有前に表示内容を確認してください。

GAME GUIDE

分からなくなったら、GAME画面で確認。

GAME GUIDEでは、DRIVER STATUS、Achievement / Personal Best、Monthly Rank、Monthly Result、Share Cardを実際の画面上で順番に案内します。

GUIDEを見直しても、EXP・LEVEL・CAREER CLASS・AchievementなどのGAMEデータはリセットされません。
PIT CREW

一人仕事に、小さな相棒を。

PITOとRONAは、DRIVERが主役のDELIPITをそばで支えるPIT CREWです。既存のGAME演出や達成のタイミングで登場します。

PHILOSOPHY

今日の1個を、ただの1個で終わらせない。

配送そのものはいつも通り。でも、今日届けた1個も積み重ねればキャリアになる。DELIPIT GAME SYSTEMは、その積み重ねを見える形にするための機能です。
